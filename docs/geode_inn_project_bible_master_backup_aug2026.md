## OVERVIEW

The Geode Inn is a hybrid digital archive, game hub, and artisan market built as an open-world MMO. It is structured as a living tree: cosmology above, market and games on the main floor, alchemical staircase between states, and catacombs below. The Inn beats at 50 BPM — the heartbeat of a sleeping giant, the universal baseline rhythm that runs through every system, every zone, every character.

**Core Architecture:** Base44 backend (database, API, web hub) + Godot game engine (arcade games, MMO zones) + GodotSteam (Steam integration)

**Core Philosophy:** Anti-FOMO. No deadlines. No scoreboards. No urgency. The Inn is mostly rest. The beat is the exception. The stillness is the rule.

**Core Mechanic:** The 42Hz Song — a cosmic frequency propagating through the Inn's mycorrhizal network, stone, water, and air. Players gather harmonic frequencies to complete the Song. When complete (44Hz), the sleeping giants wake.

**Accessibility:** Three input modalities (audio, haptic, visual Pulse Line), each independently toggleable. Minimal Mode and Silent Mode for maximum accessibility. The frequency system is fully navigable through vision alone.

## KEY SYSTEMS SUMMARY

### The 50 BPM Heartbeat
Runs through: underground altar → Inn structure → lighthouse beam → Pirate's bodhrán → Arcana's gearwork heart → starlight crystal → cabbit's purr → Pulse Line (visual). The universal baseline rhythm. The Inn was built FROM this rate, not TO it.

### The Three Artist Lenses
