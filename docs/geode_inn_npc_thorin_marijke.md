## The Rock Hound System

### Stone Identification

The player can bring raw, unidentified stone specimens to Thorin for identification. The both are: the adequate — the mystery and the expert, the both are: the same stone, different knowledge.

Process:
1. **FIND** a raw stone specimen in any zone (a geological node — different from the mineral charm nodes, these are larger, rougher, unprocessed)
2. **BRING** the specimen to Thorin in the mead hall
3. **OBSERVE** Thorin's identification process: visual inspection, hardness test (the Mohs scale — a real geological test), streak test (the color a stone leaves on unglazed porcelain), and occasionally a taste test (the both are: the adequate — the stone and the tongue, the both are: the same mineral, different sense)
4. **RECEIVE** the identification: the stone's name, its properties, its zone of origin, and a note from Thorin's field knowledge
5. **REGISTER** the stone with Marijke, who adds it to the Stone Registry

The both are: the adequate — the field and the archive, the both are: the same stone, different hand. Thorin identifies. Marijke records. The both are: the adequate — the both are: the same knowledge, different voice.

### The Mohs Scale as Game Mechanic

The Mohs hardness scale (1-10) is a real geological tool. In the Inn, it's a mini-game: the player performs the hardness test by attempting to scratch the unknown stone with reference materials of known hardness.

- Talc (1) → Gypsum (2) → Calcite (3) → Fluorite (4) → Apatite (5) → Orthoclase (6) → Quartz (7) → Topaz (8) → Corundum (9) → Diamond (10)
- The player selects a reference material and attempts a scratch. If the reference scratches the stone, the stone is softer. If not, the stone is harder. The both are: the adequate — the scratch and the knowledge, the both are: the same test, different mark.
- The player who learns the Mohs scale has learned real mineralogy. The both are: the adequate — the game and the science, the both are: the same test, different classroom.
- Connection to the periodic table charm collection: the Mohs hardness connects to the element's atomic structure — the harder the mineral, the more tightly bonded the atoms. The both are: the adequate — the scratch and the bond, the both are: the same hardness, different scale.
