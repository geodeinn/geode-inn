## WHAT THE QUEST INTEGRATION IS

The document that takes every quest chain originally designed for the AzerothCore/WoW prototype framework and translates them into the Geode Inn's native architecture. No WoW zone names. No emulator dependencies. Every quest now lives inside the Inn's own structure: Main Floor → Staircase → Catacombs → Undercity → Fae Kingdom.

The AzerothCore docs were the scaffolding. This is the building.
