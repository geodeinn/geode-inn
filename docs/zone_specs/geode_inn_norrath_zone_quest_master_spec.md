## WHAT THIS WAS

The structural template of Champions of Norrath and Return to Arms mapped onto four priority cultural regions: Egypt, Vikings (Norse Fjords), Peru (Andean Highlands), and Celtic (Sacred Grove). Each zone was designed as a self-contained chapter with its own biome, quest arc, boss encounter, embedded arcade activity, and stone rewards. Zones connected through a world map hub and a shared reputation system.

This document is DEPRECATED. The Geode Inn now uses native architecture (see Quest Integration Master Spec). Kept for reference because the class system, co-op design, and zone structure templates are still useful.

---

## WHAT WE KEEP FROM NORRATH

| Element | How It Mapped |
|---------|-------------|
| Zone-based world traversal | Each region is a chapter with a hub, spokes, and a finale |
| Class-based co-op | Up to 4 players, each class has zone-specific utility |
| Faction/reputation branching | Choices in a zone affect which Fae Court favors you |
| Loot = stones | Boss drops and zone rewards are the Inn's stone collection |
| Boss encounters per zone | Mythological bosses from the roster |
| Embedded activities | Arcade games exist INSIDE zones, not as separate menu items |

---

## WHAT WE CHANGE

| Element | How We Change It |
|---------|-----------------|
| Pacing | Exploration-heavy, not combat-heavy |
| Death | You don't die. You FORGET. No game-over screens, no restarts |
| Difficulty | Non-assertive. The Inn stays warm. Tension from environment and puzzles |
| Aesthetic | Cozy gothic alchemical, not high fantasy medieval |
| Narrative | The Silica Thread runs underneath every zone |
