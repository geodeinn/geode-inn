# Cultural Mini-Game Variants: The Americas & Europe
## Geode Inn World Map Mapping (Tier 3 Mini-Games)

This document defines the regional cultural mini-game mappings for **29 countries across The Americas and Europe** for the Geode Inn project. Each mini-game variant pairs a real-world geographic setting and regional mineral with mythological creatures from the Geode Inn Lore database, mapped directly to one of the 10 core Game Templates (A through J).

---

## DESIGN SYSTEM SUMMARY

All mini-games adhere to the three Geode Inn design pillars:
1. **Real Geography** — Set in an actual location with authentic geological features.
2. **Cultural Mythology** — Rooted directly in the region's lore and creature entries.
3. **Cryptid / Boss Mechanics** — Features a specific mythological creature as a boss or atmospheric obstacle.
