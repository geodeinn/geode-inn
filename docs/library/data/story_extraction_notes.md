# Podcast Transcript Story Extraction

## Process
1. Downloaded all .docx files from Geode Inn Google Drive (1,338 total)
2. Extracted text from Word XML format
3. Stripped host branding, intros, outros, subscribe prompts, and show-specific formatting
4. Categorized each story by source show, topics, and Inn zone
5. Deduplicated — kept longest version of each story
6. Separated internal Geode Inn docs from external research stories

## Results
- 1,338 files processed
- 458 unique stories identified
- 4 internal Geode Inn docs separated
- 453 external research stories cataloged
- ~2.1 million words of clean narrative content
- 2 errors (file access issues)
