# THE GEODE INN — Image Creation Template
## The per-image fill-out sheet. One page. Used at generation time for EVERY image the Inn makes.
### Created 2026-09-10. Masters: Visual DNA spec, Master Asset Ledger, Cinematic Directives, Linework-as-UI, Artist Mapping System.

---

## PRE-FLIGHT — before generating

**1. CLASS + ID (ledger format)**
{CLASS}-{ZONE|PRODUCT}-{NAME}-{STATE} — e.g. CYCLE-CATACOMBS-FROGLODYTE-DIG
Classes: CHAR · CYCLE · SPRITE · ZONE · ENV · PROP · EMBLEM · UI · GAZ · EGG

**2. ARTIST ASSIGNMENT**
- Foundation: Klimt + Royo ALWAYS — weight and motion in every visual, everywhere
- + Level artist (Van Gogh = Main Floor, Dalí = Cosmology, ...)
- + Zone artist (Bauer = Unseelie, Rackham = Canopy, Lee = Seelie, Escher = the Between, O'Keeffe = Hollow Earth primary...)
- "NONE" is a valid assignment. Artistless spaces (the Void) render by SUBTRACTION — nothing decorates them; things simply are. Never assign a flavor artist to a zone whose canon says "—".

**3. ANTI-CANON CHECK (retired mappings — never generate with these)**
- Kandinsky does NOT hold Clockwork Skies (retired → Dalí's melting gearwork; Kandinsky preserved in the Shadow Inn's Archive of Alternate Versions)
- Dalí does NOT hold the Fae
- Grimshaw is superseded by Bauer for the Unseelie
- Canopy City is its own Rackham zone, not part of Clockwork Skies
- If the artist in your head disagrees with the artist in the canon doc, the canon doc wins.

**4. CHARACTER CHECK**
- Canonical name law: renames applied at creation (Ragana, Brim, Lozen, Quire, the Collector, Dobbie not Dobby). No gendered pronouns in any label or text.
- All variants trace to the master portrait (consistency anchor). Role duality explicit (Odin Wanderer/Allfather).
- Standing portrait rules: soften celebrity features — posture and costume carry presence. EXCEPTION: Anthony Hopkins' eyes are the only unsoftened celebrity feature in the Inn.
- Unseelie Queen: the raven-feather cape is PERMANENT in all living-state renderings.
- Katija spelling only when Vaulknut addresses the siren directly.

**5. STONE/PROP DATA PULL (if a stone image)**
- Pull finish data from the Stone entity BEFORE rendering: canCabochon, canFacet, beadFinish, cabochonShapes. The database decides the cut — e.g. Larimar is opaque and always a smooth cabochon, NEVER faceted, no matter how pretty faceting would look.
- Photography background rule: transparent/translucent stones = light backgrounds (matte light gray universal); opaque stones = dark backgrounds.

## DURING — generation parameters

**6. TRI-MODE PLAN**
Every zone and major character carries LIVING (42Hz) / SHADOW (84Hz) / IN-BETWEEN. The ledger counts an asset complete only with all three. Shadow is NOT a filter — it's structural: outlines crack, flow bleeds, angles sharpen. In-Between: the ink hasn't decided yet.

**7. LINEWORK-AS-UI MODE (NPCs)**
Heavy cel-shaded = tradesmen · soft flowing = lore NPCs · sharp/angular = guardians · no-outline = cosmological · fragmented = crisis states. The ink IS the interface — players read function from the line before any text.

**8. CINEMATIC GATE (zones/scenes)**
All five: Hitchcock (timing, the held shot), Spielberg (music has geography), Del Toro (every surface has a wear map — every object remembers what happened to it; one anomaly per zone), Kubrick (symmetry/one-point), Coppola (layered texture).

**9. STATE PROTOCOLS**
- Echo-state visuals: desaturation protocol (the "grey Rackham" canon — reference the Silk Road spec).
- 84Hz shadow variants: use the spectral-shift script (permanent repo tool) — never hand-tint one-off shadows.
- Cycle sheets: horizontal strip of equal-width frames, 1024px, plain dark warm brown background (water critters: dark blue-green).

**10. UI/TEXT ELEMENTS**
Speech bubbles: old-school comic style, ink outlines, deliberately timeless — never modern UI widgets. Antikythera logo canon: circular mechanism atop underwater world, no text, rhythmic pulsing.

## POST — before logging

**11. SOVEREIGNTY PASS**
Strip all metadata/fingerprints at birth — every master is born clean (the MP3 principle). PNGs rendered platform-agnostic, master owned by the Inn. Never log an image with embedded generation signatures.

**12. RESOLUTION LADDER**
CHAR master ≥1024px · CYCLE 1024px strip · SPRITES crunched to 64px/32-color from CYCLE masters (never generated small) · ZONE panoramas at master resolution · PROP square masters. Engine variants are derivatives of our masters only.

**13. PROVENANCE LOG**
Every image logs its inspiration sources: which copyrighted works were referenced for CRAFT/TONE ONLY, never copied. Feeds the 37-artist copyright shield. If the image was made "in the style of" anything, the ledger row says so.

**14. QC PASS (Krista review)**
The visual orthographic memory is the QA instrument. Celebrity softening verified, cape/name/artist/canon checks, wood types verified by eye (the woodworker's call). Nothing ships to the ledger without the review.

**15. LEDGER + RETIREMENT**
Log the row (name, class, home, engine variant, status: DONE/PARTIAL/OWED/REC). If this image REPLACES existing art, the old master RETIRES to the Shadow Inn's Archive of Alternate Versions — it is never deleted. The Inn keeps its own history.

---

## THE ONE-LINE VERSION
Class it, canon it, tri-mode it, clean it, log it — and if it replaces something, the old thing goes to the Archive, not the trash.
