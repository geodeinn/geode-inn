## NOTES

- All Shadow versions use the Klimt "Death and Life" shadow aesthetic: fully petrified, dark granite, hollow void eyes, no warmth or glow
- All In-Between versions use the split: left side warm/living, right side dark/petrified, one living eye + one hollow eye
- Whisper Layer versions are translucent, warm-glowing, and player-aware (42Hz resonance state)
- Tri-mode system: Living (default) → Whisper (42Hz) → In-Between → Shadow (84Hz) — characters cycle through these states based on Inn frequency events
