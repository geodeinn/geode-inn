## The Inn as a Tree

The Geode Inn is structured as a living tree. Every level is a layer of the tree, from the canopy to the roots. Each level is a game zone with its own characters, quests, games, items, audio, and visual language.

The player progresses through the tree by unlocking zones. Each zone unlocked reveals new characters, new quests, new games, and new stones to collect. The progression is both vertical (climbing the tree) and horizontal (exploring each layer).
