# THE GEODE INN — CHARACTER CLASS MAPPING
## Standard RPG Archetypes × Inn Characters

---

## THE STAT SYSTEM

The Inn uses six core stats — adapted from traditional RPG stats but tuned to the Inn's frequency-based philosophy. Every character is rated 1-10 in each stat.

| Stat | Traditional Equivalent | Inn Meaning |
|------|----------------------|-------------|
| **MIGHT** | STR (Strength) | Physical force, presence, the weight a character carries |
| **FINESSE** | DEX (Dexterity) | Precision, agility, speed of action and thought |
| **INSIGHT** | INT (Intellect) | Pattern recognition, calculation, knowledge of systems |
| **PRESENCE** | WIS (Wisdom) | Depth of understanding, patience, the weight of experience |
| **VITALITY** | CON (Constitution) | Resilience, endurance, how long the frequency holds |
| **RESONANCE** | CHA (Charisma) | Influence, magnetism, the ability to change others' frequencies |

### Highest MIGHT: Beorn (9), Erik (8), The Sentinel (8)

The Inn's stat distribution reflects its philosophy:
- **MIGHT** is rare — the Inn is not a game of brute force
- **INSIGHT** is common — the Inn rewards knowing
- **PRESENCE** is the Inn's highest collective stat — the weight of experience matters more than the weight of a blade
- **RESONANCE** is reserved for the voices — the Siren, Cohen, the characters who change frequencies by existing
