## KEY TEXT CHANGES NEEDED

Beyond name changes, any DIRECT QUOTES from copyrighted works need to become original paraphrases:

- "There is a crack in everything, that's how the light gets in" (Cohen) → Original paraphrase needed, e.g., "The crack is where the light finds its way in" — different enough to be original
- "Hallelujah" (Cohen song title) → Can reference "the word" or "the single word" without using the song title
- "Ceci n'est pas une pipe" (Magritte painting title) → This is a French phrase from a 1929 painting. The painting is public domain (Belgian copyright life+70, Magritte died 1967, so public domain as of 2038). Actually NOT yet public domain in all jurisdictions. Safer to use: "This is not a pipe" as the concept without the French phrase, OR use it since it's a commonly referenced phrase. I'll flag this for Krista.
- "Hello, my name is Inigo Montoya" (Princess Bride) → Already not on any card. The Pirate's flavor text uses original phrasing. Safe.
- "Destiny is all" (The Last Kingdom) → This is actually a translation of the Old English/Norse concept of "wyrd" (fate). The concept is public domain. The specific phrasing "Destiny is all" is simple enough to not be copyrightable. Safe.
- "You are not walking through the Inn. The Inn is walking through you." → Original Inn quote. Safe.

## SUMMARY

**Must change:** 9 names (Mim, Radagast, Beorn, Jareth, Uhtred, Aughra, Archimedes owl, Ryuk form, Wednesday Addams → Wednesday)

**Review:** 2 names (Cabbit, Leonard Cohen)

**Safe:** All mythological figures, historical figures (70+ years deceased), and original Inn names

The replacements follow the Inn's existing naming convention: title-based descriptive names (the Constant, the Crone, the Host, the Greenward, the Bearsark, the Ravel, the Wayfarer, the Augur). The Inn's style has always been "the [Title]" — the replacements fit seamlessly.
