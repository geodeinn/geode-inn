CRYPTID TAROT - HOW TO PRINT YOUR DECK
======================================

WHAT IS IN THIS PACK
  Cryptid-Tarot-22-Cards-DOUBLE-SIDED.pdf   12 pages - print this one
  Cryptid-Tarot-22-Cards-FRONTS-ONLY.pdf     6 pages - if you would rather
                                             not print double sided
  Cards/                                    all 23 images as 300 DPI PNGs
                                             (22 cards + the card back)

FINISHED CARD SIZE
  3.5 x 5 inches - a standard photo size, so you can also send the PNGs
  to a photo lab if you would rather not print at home.

PRINTING THE DOUBLE-SIDED PDF
  1. Paper: card stock, 60-110 lb / 160-300 gsm. Matte holds the aged
     look better than gloss.
  2. Print at 100% / "Actual size". Do NOT use "Fit to page" - that will
     shrink the cards and the trim marks will no longer measure 3.5 x 5.
  3. Two-sided printing: choose FLIP ON LONG EDGE.
     The pages already alternate front, back, front, back.
  4. Cut on the corner trim marks.

IF YOUR PRINTER ONLY DOES ONE SIDE AT A TIME
  Print the odd pages (1, 3, 5, 7, 9, 11) first - these are the fronts.
  Put the stack back in, then print the even pages (2, 4, 6, 8, 10, 12).
  Run one test sheet first to learn which way your printer wants the
  paper - it is the cheapest way to avoid wasting card stock.

A NOTE ON THE CARD BACK
  The back is the same on every card and is designed to look the same
  either way up, so the deck can be read with reversals.
