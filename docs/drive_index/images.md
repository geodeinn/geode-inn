# Image folders

Every folder that holds images, with counts and a Drive link. The Image URL column in `drive_index.csv` has a direct link for every single image.

**Licences:** the folders under *Full game tabletop thingy*, *World Architecture*, *Printable cards 1* and the theme folders in *complete game image library for concepts* look like bought packs. Using them as reference while building is fine. Before any of their art goes into the game or onto the live site, check that pack's licence.

- *Printable cards 1* (and its copy in *World Architecture / Printable item cards bundle*) comes with a **personal-use licence**: printing for your own tabletop games is allowed, but not "use the artwork or card files in products for sale" or "upload the files". So none of it can go into the game, the site or the repo. The SRD item text in it is CC BY 4.0 and usable with credit; the art and homebrew cards are not.
- The other packs: no licence file was found in the folder. The shop where each was bought will have the terms.
