# Drive index: "Geode Inn-master build"

A map of the shared Google Drive folder Geode Inn-master build, listed 2026-10-29, so the builders can find any picture, video or document and see how it fits the repo.

## Pages

- [zones/](zones/README.md): one page per zone with its documents, images and videos, and related repo docs.
- [documents.md](documents.md): every written document, and whether the repo already has it.
- [images.md](images.md): every image folder with counts and links.
- [map.md](map.md): the whole folder tree.
- [drive_index.csv](drive_index.csv): every file (path, type, zone, Drive link, direct image URL), for search or import.
- [docs/](docs/): copies of the documents that were not in the repo yet (Word files converted to Markdown).

## Using the links

- **Drive link** opens the file in Google Drive.
- **Image URL** (`https://lh3.googleusercontent.com/d/<id>`) returns the picture itself, so it works in an `<img>` tag or an image field. It keeps working only while the folder stays shared by link.
- Images, videos, PDFs and archives stay in Drive; only text is copied into the repo.
- The repo was public when this index was made, so links are given only for the Inn's own documents and canon images. Folders, the bought image packs, the concept-library theme folders, the chat logs and files with keys are listed by name without a link. The full index with every link is with the client.

## Left out

- **Apps** and **Game emulator files** (2206 files: Android apps, emulators, BIOS files and ROMs of other companies' games). They are not listed or copied here and can't be used in the game.
- **Chat logs and files with keys** are listed in [documents.md](documents.md) but not copied. The "Elio - Base44" chat logs contain two Base44 file-download keys (both expired at the end of September); clean copies of the chat were made separately as Word documents.
- **Licences**: see [images.md](images.md). The bought image packs need their licence checked before their art is used in the game or on the live site; the printable cards pack is personal use only.

## Refreshing

The folder was still being organized when this was made. If files move, the index is rebuilt from a new listing, so tell the person who made it when the folder has settled.
