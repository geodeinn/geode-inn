## NOTES FOR BUILDER
1. **The Allfather image MUST be the stoic, one-eyed god version** — NOT a chibi or generic spirit. This is the primary blocker.
2. All character portraits should be displayed image-left, text-right, wrapped in the Celtic bead-frame component.
3. Celebrity-based characters (Tim Curry, Anthony Hopkins) have softened features — presence conveyed through posture, costume, gesture.
4. Refer to characters by name/title only in UI text — no gendered pronouns.
5. Linework styles are character-specific: heavy cel-shaded (tradesmen), soft/flowing (lore), sharp/angular (guardians), no-outline (cosmological), fragmented (crisis).
6. **BEAD BOARD FIX**: The custom Celtic crest bead board should NOT be the master/default. The master bead set is the 160-stone geological crop set (circular crops from real stone images in `/bead_crops/`). The Celtic beads should be a togglable alternative style, not a replacement.
