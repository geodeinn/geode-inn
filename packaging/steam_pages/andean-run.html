About This Game

Temple Run × Peru. Run the cloud causeways of Machu Picchu.

Peru holds the Andes and the Inca terraces. Blue Opal forms in the volcanic Andean soil — the frequency of mountains that sing.

Features

  • Inspired by classic arcade mechanics — Temple Run × Peru
  • Set in the Peru zone of the Geode Inn
  • Unlocks Blue Opal upon completion
  • Frequency-shift mechanics between Living (42Hz) and Shadow (84Hz) states
  • Offline playable — no internet required
  • Gamepad, keyboard, and touch controls supported
  • Collectible reward stone system synced across the Geode Inn
