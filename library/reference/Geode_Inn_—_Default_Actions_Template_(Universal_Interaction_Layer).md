# THE GEODE INN — DEFAULT ACTIONS TEMPLATE
## The Universal Interaction Layer

---

## DESIGN PHILOSOPHY

Every interactable thing in the Geode Inn — every character, stone, building, zone, object, creature, and landmark — shares the same default action set. The player always has a baseline of options. The specific thing being interacted with adds its own unique actions on top of the defaults.

The template is built on the Inn's core thesis: **naming is the saving mechanism.** Every default action is an act of attention — and attention is what makes the Inn real.

---

## THE SIX DEFAULT ACTIONS

Every interactable thing in the Inn responds to these six actions, available from a radial menu or keyboard shortcuts 1-6:

---

### 1. OBSERVE (Key: 1)
*"What is this?"*

The most basic act. The player looks at the thing. The Inn responds with a description — but the description changes based on the player's class, frequency, and progression level.

**Default response:** A short text/voice description of what the thing appears to be.

**How it scales:**
- **First observation:** Surface description — what it looks like, what it appears to be.
- **Repeated observation:** Deeper detail — the thing reveals more each time the player returns to it. The Crone's principle: "Adequate" changes with the measurer.
- **Class-specific observation:** Each class sees different things:
  - **The Sentinel** sees structural details — what it's made of, how it's supported, what it guards.
  - **The Artisan Thief** sees material composition — what stone, what metal, what it's worth, what it could become.
  - **The Siren** sees emotional resonance — what frequency it carries, what it feels like to be near.
  - **The Pirate** sees opportunity — where it leads, what's beyond it, what it connects to.
  - **The Bard** sees history — who has interacted with it before, what stories it carries.

**Universal rule:** Observation is always free. It costs no mana, no cooldown, no resource. The Inn never charges for looking. Looking is the saving mechanism.

---

### 2. NAME (Key: 2)
*"What do I call this?"*

The player assigns a name or title to the thing. This is the Inn's core mechanic — the act of naming is the act of making the thing real. Once named, the thing is saved to the player's journal and becomes part of their personal Inn.

**Default response:** A naming prompt appears. The player can type a name or choose from suggested names based on their class's observation.

**How it scales:**
- **Naming a character:** The character acknowledges the name. Some characters react — the Crone might say "Adequate" or "Inadequate" depending on the name. The Duck doesn't react at all. The Duck doesn't care.
- **Naming a stone:** The stone is added to the player's collection journal with the name. If the player names it correctly (matching its real mineral name), the stone's full properties are revealed. If the player names it creatively, the stone gets a custom entry — the player's name for it becomes its name in their journal.
- **Naming a place:** The player can name uncharted zones, clearings, or landmarks. Named places appear on the Cartographer's map. Other players can see the names if multiplayer naming is enabled.
- **Naming a creature:** Creatures that are named become non-hostile. The naming is: the taming. The Fae Kingdom's creatures respond to names — the correct name (from lore) grants a bonus. A creative name grants the creature's friendship but not its lore bonus.

**Universal rule:** Naming is always available. It costs no mana. But each thing can only be named ONCE per player. The naming is permanent. The permanence is: the adequate.

---

### 3. LISTEN (Key: 3)
*"What does this sound like?"*

The player listens to the thing's frequency. Every thing in the Inn has a frequency — a hum, a tone, a vibration. The Listen action reveals it.

**Default response:** The thing's frequency plays — a tone, a chord, or a rhythm. Visual feedback: a subtle vibration animation on the thing, and a frequency visualization (waveform or particle effect) around it.

**How it scales:**
- **Stones:** Each stone plays a unique tone based on mineral hardness (Mohs scale → frequency mapping). The geode cave is: the symphony of all collected stones playing together.
- **Characters:** Each character plays their instrument's frequency at their Hz level. The Astronomer's violin. The Crone's silence. The Pirate's bodhrán. The Guest's music box. The Duck's... quack. The quack is: always off-key. The off-key is: the adequate.
- **Zones:** Each zone has an ambient frequency — the Norse zone's taglharpa drone, the coast's 50 BPM heartbeat, the catacombs' deep stone resonance. Listening to a zone reveals its base frequency.
- **Buildings:** Buildings play their architectural frequency — additive structures play layered tones (each material adds a note), subtractive structures play the resonance of the negative space (the emptiness has a tone).
- **Water:** Water features play their current mechanic — still water is a sustained note, moving water is a flowing melody, deep water drops to sub-bass frequencies.

**Universal rule:** Listening costs 1 SONG mana. If the player has no SONG mana, the frequency plays at reduced volume (a whisper). The Inn never fully silences a listener. The whisper is: the adequate.

---

### 4. TOUCH (Key: 4)
*"What does this feel like?"*

The player makes physical contact with the thing. Touch reveals texture, temperature, vibration, and — for some things — a memory.

**Default response:** Haptic feedback description — texture, weight, temperature, and a subtle vibration if the thing carries a frequency.

**How it scales:**
- **Stones:** Touch reveals the stone's Mohs hardness (through a tactile description — "smooth as glass," "rough as sandpaper," "warm to the touch"), its temperature (some stones are naturally cold, some warm), and — for progressed players — a memory flash. The stone remembers where it was formed. The touch is: the remembering.
- **Characters:** Touch is consent-gated. The character must be willing. If willing, touch reveals:
  - Their heartbeat (50 BPM for most Inn residents — the Inn's resting rate)
  - Their surface temperature (the Guest is cold — the borrowed body doesn't generate heat. The Catalyst is warm — the fire of growth. The Crone is neutral — the temperature of measurement.)
  - Their texture (the Sentinel's fur — soft, dense, the cat-person's coat. The Vessel's gecko skin — dry, delicate, the skin of something that was extinct. The Shifting Man's surface — changes with form.)
- **Buildings:** Touch reveals the building's material composition. Additive buildings feel layered — each material is a different texture. Subtractive buildings feel carved — the stone is smooth where it was cut, rough where it wasn't.
- **Water:** Touch reveals temperature and current. Deep water pulls. Still water reflects. The Current mechanic triggers — touching water in a zone with Current may move the player.
- **Bones (Bone Room):** Touch reveals the bone's history — what animal, what life, what death. The Examiner would know this data. The player gets a simplified version: "This was a runner. This was a flyer. This was a swimmer." The bone remembers what it was.

**Universal rule:** Touch is always available but may be refused by characters. Refusal is not rejection — it is the character's boundary. The boundary is: the adequate. The Duck always accepts touch. The Duck doesn't understand boundaries. The not-understanding is: also the adequate.

---

### 5. OFFER (Key: 5)
*"What can I give this?"*

The player offers something from their inventory to the thing. Not all things accept offers. Characters may accept or refuse. Stones may absorb or reject. Zones may transform.

**Default response:** An offer prompt — the player selects an item from their inventory and offers it.

**How it scales:**
- **Characters:** Offering items to characters builds reputation. Each character has preferences:
  - **Erik** accepts mead, firewood, and good stories. Rejects nothing — Erik accepts everything with the same warmth. The warmth is: the adequate.
  - **The Crone** accepts nothing. The Crone needs nothing. The refusal is: the adequate. (Exception: Leonard Cohen's "Hallelujah" — the Crone asks to hear it again. The asking is: the first thing the Crone has ever asked for.)
  - **The Duck** accepts shiny things. The Duck will take anything shiny and add it to the collection. The Duck doesn't differentiate between a diamond and a bottle cap. The not-differentiating is: the adequate.
  - **Naut** accepts rare books. The scholar doesn't want treasure — the scholar wants reading material. Offering a rare book unlocks hidden quests.
  - **Belladonna** accepts bones, dried flowers, and dark humor. The last one isn't an item — it's a dialogue option. Belladonna accepts dark humor as currency. The deadpan is: the payment.
  - **The Guest** accepts nothing material. The Guest accepts: time. Offering time (waiting with the Guest) is the only gift Death wants. The time is: the adequate.
- **Stones:** Offering a stone to another stone can create a resonance pair — two stones that harmonize. Offering a stone to a building material can reinforce the structure. Offering a stone to water changes the water's frequency.
- **Zones:** Offering items to a zone's central landmark can trigger zone events. Offering mead to the mead hall's central fire makes the fire brighter (the mead feeds the flame — the alcohol is: the fuel). Offering a bone to the Undercity's ribcage wall creates a new niche display.
- **Water:** Offering a stone to deep water is the "sinking" mechanic — the stone sinks, the water accepts it, and the water's frequency shifts. This is how the deep-water game zone's difficulty is tuned — players "feed" the water to change its frequency.

**Universal rule:** Offering is always available if the player has inventory items. The item is consumed on acceptance. Refusal does not consume the item. The refusal is: the character keeping their boundary. The boundary is: the adequate.

---

### 6. REMEMBER (Key: 6)
*"What happened here?"*

The player accesses the memory of the thing — its history, its story, its previous interactions. Remember is the Inn's archive mechanic — every thing in the Inn carries a record, and the player can access it.

**Default response:** A memory prompt — text, voice, or visual flashback depending on the thing and the player's progression level.

**How it scales:**
- **Characters:** Remember reveals the character's backstory — the memories they're willing to share. Deeper progression unlocks deeper memories. The Crone's memories are: measurements. The Pirate's memories are: the after. The Guest's memories are: everyone who has ever died (accessed one at a time, each one a quest in itself).
- **Stones:** Remember reveals the stone's geological history — where it formed, how it traveled, what it was before it was a stone. The 164 stones each carry a geological memory that connects to a world map location.
- **Zones:** Remember reveals the zone's history — who built it, who lived there, what happened. The catacombs remember the Crimean Goths. The mead hall remembers every feast. The Bone Room remembers every bone.
- **Buildings:** Remember reveals the building's construction — who built it, what materials, what technique. The Additive buildings remember their stacking. The Subtractive buildings remember their carving.
- **Water:** Remember reveals what the water has seen — everything that has crossed it, everything that has sunk into it, everything that has been carried by its current. The deep water is: the deepest archive in the Inn.
- **Places of death (Undercity, catacombs):** Remember reveals the dead. Each remembrance is a small quest — the player learns who this was, what they cared about, what they left behind. The Bone Keeper's thesis: the bone is the last structure the body builds. The remembering is: the honoring.

**Universal rule:** Remember costs 1 SILENCE mana. If the player has no SILENCE mana, the memory is fragmented — partial, faded, incomplete. The fragment is: not a failure. The fragment is: the adequate. Some memories are meant to stay partial.

## THE ACTION WHEEL

The six actions appear in a radial menu when the player approaches an interactable thing:

```
        OBSERVE
      /         \
  NAME           LISTEN
     |           |
  OFFER        TOUCH
      \         /
       REMEMBER
```

**Keyboard:** Keys 1-6 select the action.
**Controller:** D-pad or right stick navigates the wheel.
**Touch:** Tap the thing, tap the action from the popup menu.

**Auto-suggest:** The Inn highlights the most relevant action based on context. If the player approaches a stone for the first time, OBSERVE is highlighted. If the player has a stone in their inventory near a water feature, OFFER is highlighted. If the player stands in the Bone Room, REMEMBER is highlighted.

## CLASS-SPECIFIC ACTION MODIFIERS

Each playable class modifies the default actions:

### The Sentinel (River)
- **OBSERVE** reveals structural weaknesses and defensive properties.
- **TOUCH** reveals load-bearing capacity and stability.
- **OFFER** can include placing Bar Backs as guardians near the thing.
- **Unique Action: GUARD** — the Sentinel can station near any thing and enter Vigil Mode. While guarding, the thing cannot be affected by negative effects.

### The Artisan Thief (Krista)
- **OBSERVE** reveals material composition, mineral type, and craft potential.
- **TOUCH** reveals workability — can this be carved, wrapped, set, or cast?
- **OFFER** can include crafted charms (wire-wrapped, set, engraved).
- **Unique Action: CRAFT** — the Artisan Thief can craft at any workbench, turning observed materials into items. The Craft action uses the alchemical chain progression.

### The Siren
- **OBSERVE** reveals emotional frequency and resonance patterns.
- **LISTEN** is enhanced — the Siren hears frequencies other classes can't. The Siren can hear the inner voice of things.
- **TOUCH** reveals the thing's emotional history — what it has felt.
- **Unique Action: HARMONIZE** — the Siren can match her voice to any thing's frequency, creating a resonance that calms, attracts, or reveals. The Harmonize is: the Dual Cadence applied to the world.

### The Pirate
- **OBSERVE** reveals connections — where this thing leads, what's beyond it.
- **LISTEN** reveals the Pirate's drum cadence syncing with the thing's rhythm.
- **REMEMBER** is enhanced — the Pirate can access the "after" — what happened to this thing after its main story ended.
- **Unique Action: CHART** — the Pirate can mark any thing as a waypoint on the Compass That Points Forward. Waypoints create fast-travel routes.

### The Bard
- **OBSERVE** is enhanced — the Bard sees who has interacted with this thing before (the gossip).
- **NAME** is enhanced — the Bard's names carry more weight. A Bard-named thing gets a bonus to its primary stat.
- **REMEMBER** is enhanced — the Bard accesses the Inn's gossip archive about this thing.
- **Unique Action: SING** — the Bard can compose a half-finished song about any thing. The song, once composed, becomes a permanent buff for that thing — +1 to its primary stat for all players. The song is: unfinished. The unfinished is: the potential that others can complete.

## THING-SPECIFIC UNIQUE ACTIONS

On top of the six defaults, specific things add their own unique actions:

### Characters
- **TALK** — available for all characters. Opens dialogue. The dialogue system is: the character's cadence, instrument, and frequency translated into speech patterns.
- **QUEST** — available for characters with quests. Opens the questline. Characters with active quests have a subtle visual indicator (a frequency pulse around them).
- **FOLLOW** — available for companion characters. The companion joins the player. The Duck follows if the player has something shiny. The Duck leaves if someone else has something shinier.

### Stones
- **COLLECT** — adds the stone to the player's collection. The stone appears in the geode cave. Each collected stone adds its unique tone to the cave's symphony.
- **COMBINE** — available when two or more resonance-compatible stones are in the player's collection. Creates resonance pairs.

### Buildings
- **ENTER** — available for enterable structures. Transitions to the building's interior.
- **BUILD** — available at construction sites. Opens the building system (Additive/Subtractive).
- **IMPROVE** — available for player-built structures. Uses crafting materials to upgrade.

### Zones
- **TRAVEL** — transitions to the zone. Zone transitions play a short musical sting (the zone's signature frequency).
- **EXPLORE** — available in zones with unexplored areas. Reveals a portion of the zone map.

### Water Features
- **DIVE** — available at deep water. Transitions to the underwater zone.
- **FERRY** — available where Charon operates. Transitions across water (the Current mechanic may alter the path).
- **FISH** — available at coast and river zones. The fishing minigame yields stones, items, and occasionally water creature encounters.

### Bones (Bone Room)
- **EXAMINE** — available for all bones. Reveals the bone's biological data (the Examiner's domain). Progressed players see full archaeological data.
- **ARRANGE** — available during the Bone Keeper's questline. The artistic act — positioning the bone, angling the light, naming what you see.

### Books
- **READ** — opens the book's content. Public domain books display full text. Copyrighted books link to archive.org or local catalogs.
- **TRANSLATE** — available for books in the translation system. Opens the BookTranslation entity.

## THE SEVENTH ACTION: SIT

Hidden. Not on the radial menu. Not in the tutorial. Discovered by the player when they do nothing for 10 seconds near an interactable thing.

**SIT** (Key: 7, or just... wait)

The player sits near the thing. Nothing happens. The thing continues to be itself. The Inn continues to run. The ambient music plays. The 50 BPM heartbeat continues.

But: if the player sits near a character long enough, the character may come sit nearby. Not to talk. Not to interact. Just to be there. The "just to be" mechanic — the one we designed in the mead hall. The Inn's deepest interaction is: no interaction. The presence is: the adequate.

**Sitting milestones:**
- **30 seconds:** The ambient music gets slightly louder. The zone's frequency becomes more prominent.
- **2 minutes:** A nearby character may approach and sit. They don't speak. They sit. The Erik of this zone brings mead. The Belladonna of this zone brings a bone. The Duck brings a shiny thing.
- **5 minutes:** The zone's "quiet track" plays — a stripped-down version of the zone's music, just the base frequency, no melody. The 42Hz Song is: audible. Barely. A hum underneath everything.
- **10 minutes:** The "Einstein moment" — the player realizes they are part of the Inn. The observer's presence makes the Inn real. The Inn was always here. The player made it real by sitting still long enough to notice. The achievement unlocks: "You looked."

**Universal rule:** SIT is always available. It costs nothing. It gives nothing — except the thing the Inn was always trying to give: the presence. The presence is: the adequate. The adequate is: enough.

## THE FULL INTERACTION STACK

When a player approaches any interactable thing in the Inn:

1. **Auto-observe** — a brief tooltip appears with the thing's name (if already named) or "???" (if unnamed).
2. **Action wheel** — the six default actions appear. The most contextually relevant action is highlighted.
3. **Class modifier** — the player's class adds one unique action to the wheel.
4. **Thing-specific action** — the thing adds its own unique action(s) to the wheel.
5. **SIT** — always available, never shown, always enough.

**Maximum actions on the wheel:** 6 (default) + 1 (class) + 1-3 (thing-specific) = 8-10 actions maximum. Clean. Readable. The adequate.

## INTERACTION EXAMPLES

### Example 1: The player approaches a stone in the Peruvian zone

**Available actions:**
1. OBSERVE — "A rough stone, dark green, with white veining. It looks like it came from the terrace above."
2. NAME — Prompt: "What do you call this?" (Correct: Malachite. The stone's full properties are revealed.)
3. LISTEN — The stone plays a tone. Malachite's Mohs hardness is 3.5-4, mapping to a mid-range frequency.
4. TOUCH — "Cool to the touch. Smooth where the water has worn it. Rough where it was broken. It feels: heavy for its size."
5. OFFER — Select an item to offer. Offering water to the stone may trigger a geological memory.
6. REMEMBER — "This stone formed in the copper-rich zones of the terrace. The One Who Tends walked over it many times. It remembers: the weight of footsteps."
7. (Class) CRAFT — (Artisan Thief) The stone can be carved, ground, or polished. Malachite dust is toxic — the Artisan Thief knows this.
8. (Thing) COLLECT — Add to collection. The stone appears in the geode cave. Its tone joins the symphony.

### Example 2: The player approaches Erik in the mead hall

**Available actions:**
1. OBSERVE — "A broad-shouldered figure by the fire, smiling at nothing. The fire reflects in eyes that have seen fire before."
2. NAME — Already named: Erik. (The player can add a nickname. Erik accepts all nicknames with the same warmth.)
3. LISTEN — Erik's taglharpa plays a low, warm drone. ~100Hz. The fire crackles in time.
4. TOUCH — (Consent-gated) "Warm. Very warm. The heartbeat is 50 BPM — the Inn's resting rate. The skin feels like it remembers heat."
5. OFFER — Erik accepts: mead, firewood, stories. Rejects: nothing.
6. REMEMBER — "Erik died by fire. Erik came back. Erik chose to be the fire that welcomes. The wound underneath the warmth is: the warmth itself."
7. (Class) SING — (Bard) Compose a half-finished song about Erik. Erik's primary stat (PRESENCE) gets +1 for all players.
8. (Thing) TALK — Opens dialogue.
9. (Thing) QUEST — "The Warm Fire" questline is available.
10. (Thing) FOLLOW — Erik doesn't follow. Erik stays by the fire. The staying is: the adequate.

### Example 3: The player stands in the Bone Room

**Available actions (on the room itself):**
1. OBSERVE — "A quiet room below the mead hall. One window. One workbench. Bones in the light."
2. NAME — Already named: The Bone Room.
3. LISTEN — Near silence. The faintest stone resonance from the flagstone. A single deer femur percussion note, barely audible, every 8 seconds.
4. TOUCH — "The stone is cool. The wood is smooth. The air is still. The room feels: patient."
5. OFFER — Offering a bone adds it to the workbench. Offering a dried flower adds it to the ceiling beams.
6. REMEMBER — "The meadery owner's wife works here. The elf twins visit. Belladonna sits in the corner. The Crone came once and said 'adequate.' The room remembers: the quiet."
7. SIT — The player sits in the Bone Keeper's chair by the window. The afternoon light moves across the bones. The Bone Keeper continues working. Nobody speaks. The coals glow.

## TECHNICAL IMPLEMENTATION NOTES

### Data Structure
Every interactable thing in the Inn carries an `interactions` object:

```
{
  "id": "stone_malachite_peru",
  "type": "stone",
  "name": "Malachite",
  "isNamed": true,
  "interactions": {
    "observe": { "text": "...", "classVariants": { "sentinel": "...", "artisanThief": "..." } },
    "name": { "isNamed": true, "correctName": "Malachite" },
    "listen": { "frequency": 340, "instrument": "stone_tone", "mohs": 3.75 },
    "touch": { "texture": "smooth_rough", "temperature": "cool", "memory": "..." },
    "offer": { "accepts": ["water", "cloth"], "rejects": [], "effects": { "water": "geological_memory" } },
    "remember": { "memory": "...", "manaCost": 1, "type": "SILENCE" },
    "sit": { "duration": 0, "milestones": [30, 120, 300, 600] },
    "uniqueActions": ["collect", "combine"]
  },
  "classModifiers": {
    "sentinel": { "uniqueAction": "guard" },
    "artisanThief": { "uniqueAction": "craft" },
    "siren": { "uniqueAction": "harmonize" },
    "pirate": { "uniqueAction": "chart" },
    "bard": { "uniqueAction": "sing" }
  }
}
```

### Performance
- The action wheel renders only when the player is within interaction range (2 meters default, 5 meters for large objects/zones).
- Observation text is cached after first viewing. Repeated observations pull from cache + progression delta.
- Listen audio is pre-loaded per zone (all zone frequencies load on zone entry). Individual thing frequencies are small audio files (<50KB each).
- Remember memories are text-based with optional voice — loaded on demand, not pre-loaded.
- SIT has no server call. It's entirely client-side — a timer and an achievement check. The adequate is: no bandwidth.
