# Geode Inn — Standalone Web Games

Self-contained HTML5 games. No Base44 dependency. No internet required.
Each game is a single .html file — open it in any browser, anywhere, offline.

## How to Play
1. Download any .html file
2. Open it in a browser
3. Play

## Controls
- Keyboard: Arrow keys + Space + Z/X
- Touch: On-screen buttons (auto-enabled on mobile)
- Gamepad: Via browser Gamepad API
