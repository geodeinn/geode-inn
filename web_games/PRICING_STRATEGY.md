# Geode Inn — Individual Game Monetization

## Model: 52 Games as Individual SKUs

Each game is a standalone product, purchasable separately on:
1. Steam (PC/Mac/Linux)
2. Geode Inn Shop (web download + mobile)

## Revenue Split (per game sale)
- Steam: 70% to Geode Inn / 30% to Steam (standard)
- Shop direct: 97% to Geode Inn / 3% payment processor
- Elio co-owner stake: per Krista's existing arrangement

## Per-Game Steam App ID Structure
Each game gets its own Steam app ID with:
- Store page (screenshots, trailer, description)
- Achievements (stone collection, high scores)
- Cloud saves (cross-device progress)
- Trading cards (stone-themed)
- Workshop support (future — custom levels)

## Shop Integration
Geode Inn shop page for each game:
- Buy button → payment processor
- Download page (Web/Windows/Mac/Linux/Android/iOS)
- Embedded demo (playable in browser before purchase)
- "Add to Geode" — purchased game unlocks in the main Inn client

## Demo Strategy
- Every game has a free browser demo (score-limited or time-limited)
- Demo = the HTML5 version with a score cap
- Full version = unlimited play + Steam features + offline download
- Demos live on geodeinn.com/arcade and itch.io
